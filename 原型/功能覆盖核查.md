## 入口与推荐试玩

左侧 **Desk**，或者 World 输入 `Open world desk.`。快捷键 G 在不聚焦输入框/按钮时打开，且可以在 Keyboard preferences 中修改。

1. **配置与人物**：You & your roles → People in your world → 编辑/添加 → 预览 → 保存。归档 Emma 没有继任人会被拒绝；可在医院添加无职责人物再作交接。
2. **生活事件**：World `Go to the kitchen.` → `Prepare breakfast.` → Start activity → `Wait for five minutes.` → Events。事件可能在等待检查点暂停计划，处理后明确继续或取消。
3. **预约与成果**：完成原医院示例 → Tasks & written work → Summarize the next steps → 接受 → Writing desk。缺信息版本会退回；修订后生成新的不可编辑版本。
4. **表达与隐私**：消息下 Save expression → Words to keep；Your data 可导出/隐藏/移除音频/删世界。永久删除只作用于当前故事。
5. **故障恢复**：When something fails 设置下一次 World 指令故障，再返回执行实际行动。处理后回复失败时使用 Retry reply only，检查物品和时钟未再变化。
6. **药房样例**：A pharmacy sample 创建独立测试世界，处方来源明确；Leo IM `Please collect my prescription.`。不向当前正常就诊凭空加处方。

7. **多步计划**：Desk → Your itinerary → Create itinerary，默认钥匙三步可直接预览保存。World 也可输入 `Go to the entrance then take the house key then give the key to Sarah`。逐项 Run next step 或明确选择 Run remaining steps；连续行动遇事件、时间节点、条件变化或 IM 草稿会暂停并保留余程。可编辑未执行步骤，原完成记录保留。`Message Sarah: I have the key with me.` 只填草稿；自己 Send 后才记为已送达。
8. **跨日预约**：Appointment slots 切换 Tomorrow 或 Day N，选择时段 → Emma 草稿 → 自己发送。也可 IM `Please book an appointment at 09:00 tomorrow.`。今天结束不会错过明天的预约；到对应日才登记。
9. **候补**：到 Hospital / Reception 并携带 ID，Desk → Hospital standby → Ask to join standby → 自己发送 → World `Wait for 5 minutes.` → 读取 Emma 的时段提议 → 准备接受草稿并自己发送。时段提议未接受前没有预约；停止等待不退队。`Please leave the standby queue.` 才明确退出。
10. **失约后续**：接受钥匙后，任务详情或 Desk → Promises & follow-ups 查看截止。Sarah IM `Please change the key handover to 14:00 today.` 是明确延期。逾期后 `Please arrange a new key handover at 09:00 tomorrow.` 会建立独立后续；实际交付完成后续，原失约保留。默认晨间截止 12:00，可在未接受任务预设中改。

11. **多段日程**：Desk → People in your world → 选择 NPC → Daily routine；每段分别设置起止时间、场景/区域、英文活动、可否回复。空档不虚构所在位置。医院必要职责不可随意留下服务空档；已有承诺与在途材料工作受保护。
12. **物品消耗与遗落**：World `Go to the kitchen.` → `Take the water bottle.` → `Drink some water.`；三份喝完后需回厨房 `Refill the water bottle.`。到 Living Room `Take the snack.` / `Eat the snack.`，只能吃一次。`Drop my ID card.` 后，只有返回原区域 `Take my ID card.` 才能找回。
13. **录音检查**：录完后输入框附近 Review voice draft；可试听、改英文转写、Record again 或 Use text only，均不会自动发送。麦克风权限未返回时 Escape 可取消；之后迟到的权限与识别回调不会覆盖草稿。
14. **收听列表**：Desk → Voice & listening 或 World `Open voice queue.`。列表不展示未读语音正文，Play / pause 保持当前输入对象，Open IM 才切到对应人物。
15. **对话片段**：在任一 NPC IM 发一条普通消息，待结算分钟会显示在输入区；切换联系人、查看状态或使用 Assistant 不推进时间。发送 `End this conversation.` 会结算当前片段一次；也可直接提交等待或移动，让片段先结算，再开始世界行动。
