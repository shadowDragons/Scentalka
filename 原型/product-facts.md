# 原型事实与实现范围

来源：根目录《产品文档.md》，尤其第 4、18 节；用户选择视觉 A，品牌未定。

这是本地 HTML / Canvas / JavaScript 交互设计原型，不是生产实现；不连接 AI、数据库、Redis 或付费语音服务。NPC 回复由本地上下文规则生成，英文自由表达支持有限，无法识别时会给出当前可演示的指令。

NPC 语音使用设备可用的英语浏览器语音，每条新消息独立选择语音或文字并保存。真人输入优先浏览器英语语音识别；不支持、权限拒绝或连接失败时明确显示状态并保留文字入口。录制不伪造成功，识别文本先进入草稿，用户自行发送。

本地保存当前世界；演示存档是独立预设，不构成用户已接受任务。切换存档不覆盖另一存档。现实时间不推进世界。

地图按固定房间组合；不开放地图编辑。角色和代表性节奏字段可预览校验保存，已有历史不可编辑。原型没有实现产品文档中所有生产级配置字段、并发服务及模型故障恢复机制。
